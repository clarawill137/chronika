# Хроника — поиск по истории

Расширение SillyTavern: модель сама ищет старые детали ролки — в сообщениях чата (включая давно скрытые)
и в памяти (записи лорбуков, например от STMemoryBooks) — и дочитывает нужную сцену целиком.
Работает как инструменты (function calling): `story_search` и `story_read`.

## Установка

**Расширения → Install extension →** `https://github.com/clarawill137/chronika` → Install, потом обновить страницу.
В пресете должно быть включено «Enable function calling».

Если раньше стояла старая «Хроника — поиск по истории» (папка `hedy-recall`) — удалить её в Manage Extensions
до установки: у обеих одинаковые инструменты. Настройки переезжают сами (тот же ключ настроек).

## Как ищет

- **Сообщения чата** — все, кроме последних N (они и так в контексте), с номерами; `story_read` читает до 8 подряд.
- **Память** — записи лорбуков:
  - в обычном чате — лорбуки из поля «Лорбуки с памятью»;
  - в чате, отмеченном эпохой в расширении **«Священный таймлайн»**, — меморибук этой эпохи и Хроника мира,
    причём только то, что видно отсюда: на дату сюжета и тому, кто сейчас говорит (будущее и чужие тайны
    отсекает таймлайн). Поле в настройках здесь не используется.
- Результаты поиска после ответа сворачиваются в чате, чтобы не занимать контекст.

Проверка вручную: `/recall письм вокзал` — окно с тем, что увидит модель.
